# ProjectCollab live demo workspace

This workspace demonstrates a complete delivery path for a small collaboration product called ProjectPulse. The product, pipeline tasks, unit tests, build, release package, and evidence generation are dependency-free and work offline.

Open this folder in ProjectCollab, open the Delivery Center, and choose **Set Up Workspace**. The six convention-based tasks are discovered automatically.

To run the delivered application independently:

```bash
npm start
```

Then open `http://127.0.0.1:4173`.

See `DEMO.md` for the presenter script.
